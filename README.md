# Антракт

Планер актёра для съёмок, репетиций, спектаклей и личных дел. Интерфейс работает на телефонах и компьютерах. Личные записи можно добавлять без входа.

[Открыть планер на GitHub Pages](https://arishkawolf.github.io/planer/).

## Как пользоваться

- Выбери вид «День», «Неделя», «Месяц» или «Год». Нажатие на заголовок периода открывает выбор даты.
- Фильтры меняют сетку календаря и список событий за выбранный день. «Мои спектакли» показывает спектакли, в которых Дмитрий Нестеров указан в блоке «Роли исполняют» на сайте театра. Если на роль указаны несколько исполнителей, проверь состав на конкретную дату в театре. Вопросы в чате учитывают полное расписание.
- Дни съёмок выделяются бордовым, важные события зелёным. В карточке личного события есть флажок «Важное событие», в карточке показа — кнопка «Отметить важным».
- Добавь событие кнопкой «Событие» или напиши помощнику «Съёмка 10 ноября», «Репетиция завтра в 14:30» или «Кастинг 15.11.2026 в 12». Дату без года помощник ищет начиная с сегодняшнего дня.
- «Репетиция с 10 до 18» предложит сохранить интервал на выбранный день. С явной датой, например «Репетиция завтра с 10 до 18», запись сохранится сразу. В виде «День» шкала показывает занятое время.
- «Съёмка 21 и 25» создаст две записи в открытом месяце. Можно указать месяц явно, например «Съёмка 21 и 25 декабря в 10».
- Спроси «Когда у меня съёмка?», «Что у меня завтра?» или «Когда у меня выходной?». Свободным считается день без личных событий и показов из афиши. Если за этот месяц нет опубликованной афиши, помощник это отметит.
- Чтобы изменить или удалить свою запись, нажми на неё в списке дел дня. В карточке показа из афиши можно убрать отдельный показ из календаря, а в разделе «Афиша → Скрытые показы» вернуть его.
- Планер и афиша используют московские даты. Переписка сбрасывается при перезагрузке, добавленные через неё события сохраняются.
- Нажми «Поделиться» и отправь ссылку для просмотра копии личных событий на другом устройстве. После изменений нужно создать новую ссылку. Расписание доступно всем, у кого есть ссылка.

## Локальный запуск

Запусти из каталога проекта `python -m http.server 8765` и открой [планер](http://localhost:8765/). Сборка и сторонние JavaScript-пакеты не нужны.

Личные события хранятся в текущем браузере. Очистка данных сайта удаляет локальные записи.

## GitHub Pages и афиша

В репозитории выбери **Settings → Pages → Source → GitHub Actions**. Изменения в `main` публикуются с последней сохранённой афишей. Автоматическая проверка сайта театра выполняется раз в три дня. Запустить её вручную можно через **Actions → Run workflow**.

`sync_afisha.py` получает афишу Новошахтинского драматического театра за предыдущий, текущий и два следующих месяца. При сбое прямого запроса он пробует получить ту же публичную страницу через [AllOrigins](https://allorigins.win/). Если оба запроса не удались, публикация использует последние доступные данные. На GitHub расписание публичного репозитория может отключиться после 60 дней без активности. Его можно снова включить во вкладке **Actions**.

## Синхронизация между устройствами

1. Создай проект Supabase и выполни [supabase-sync.sql](supabase-sync.sql) в его SQL Editor. Результат даст две приватные ссылки. `edit_link` позволяет смотреть и менять календарь, `view_link` позволяет только смотреть.
2. В [sync-config.js](sync-config.js) укажи URL проекта и публичный ключ `sb_publishable_…`. Отправь изменения в `main`, чтобы GitHub Pages обновился. Ссылки из SQL храни отдельно от репозитория.
3. Открой нужную ссылку на каждом устройстве. Планер запомнит подключение в браузере и будет проверять изменения каждые 15 секунд, пока страница открыта. Если на устройстве уже есть записи, открой «Общий календарь → Управление → Перенести записи с этого устройства» по ссылке для редактирования.

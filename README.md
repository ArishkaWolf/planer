# Антракт

Личный планер актёра театра и кино. Помогает держать съёмки, репетиции, спектакли и личные дела в одном расписании.

[Открыть Антракт](https://arishkawolf.github.io/planer/)

## Возможности

- Календарь с просмотром года, месяца, недели и дня.
- Помощник для быстрой записи обычным сообщением, например «Репа в пятницу с 10 до 18» или «Съёмка 21 и 25 ноября».
- Ответы на вопросы о ближайших событиях и свободных днях.
- Автоматическая загрузка афиши Новошахтинского драматического театра раз в три дня.
- Фильтр «Мои спектакли» для постановок, где Дмитрий Нестеров указан в составе исполнителей.
- Совместимые фильтры по съёмкам, репетициям, спектаклям, чайхане, концертам и личным делам.
- Приоритет съёмок с выделением всего дня. Спектакли без участия Дмитрия отображаются серым, важные события отмечаются зелёным.
- Изменение и удаление личных событий, скрытие отдельных показов из афиши.
- Ссылка для просмотра копии расписания.

Интерфейс рассчитан прежде всего на телефон и адаптирован для компьютера. На iPhone сайт можно добавить на домашний экран через меню Safari «Поделиться → На экран “Домой”» — ярлык будет называться «Антракт» и получит иконку с бордовым бегемотом.

Пока облачное хранение не подключено, личные записи сохраняются в текущем браузере.
